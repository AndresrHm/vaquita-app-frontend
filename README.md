# proyecto-vaquita
TP Final para la materia de Proyectos de Software

Al clonar el repo usar:
1. nvm use (así usan la versión de node que corresponde)
2. npm install (por las dudas)

Si tienen alguna advertencia en el punto uno tiren un nvm install y luego siguen

Stack:
- React
- Vite
- Tailwind
- shadcn/ui (componentes)
- lucide-react (iconos)
